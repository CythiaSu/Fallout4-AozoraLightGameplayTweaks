# Aozora Light Gameplay Tweaks 1.1.0

青空轻度娱乐调整 1.1.0 是一个轻量、玩家专属、按存档保存配置的 Fallout 4 MCM 调整 MOD。

## Features

- Fast AP recovery outside combat; vanilla AP costs return in combat.
- 非战斗状态 AP 快速回复，进入战斗后恢复原版 AP 消耗。
- Water breathing for the player.
- 玩家水下呼吸。
- No fall damage for the player.
- 玩家无跌落伤害。
- Unlimited carry weight for the player.
- 玩家无限负重。

All features are controlled from the MCM configuration page. The effects are player-only and do not use global GMST edits.

所有功能都在 MCM 的配置页面中控制。效果只作用于玩家，不使用全局 GMST 修改。

## Requirements

Fallout 4, F4SE, Address Library for F4SE Plugins, and MCM are required. GOE, Prisma UI Framework, LooksMenu, and DLC are not required.

需要 Fallout 4、F4SE、Address Library for F4SE Plugins 和 MCM。不需要 GOE、Prisma UI Framework、LooksMenu 或任何 DLC。
