# Aozora Light Gameplay Tweaks

青空轻度娱乐调整是一款轻量 Fallout 4 MCM 便利 MOD。

This mod only affects the player and stores its settings with the current save.

本 MOD 只作用于玩家，配置跟随当前存档保存。

It does not modify global game settings, so it does not affect enemies or other NPCs.

本 MOD 不修改全局游戏设置，因此不会影响敌人或其他 NPC。

All features can be adjusted at any time through MCM.

所有功能都可以随时通过 MCM 调整。

## Features

- Fast AP recovery outside combat.
- 非战斗状态 AP 快速回复。
- Water breathing.
- 水下呼吸。
- No fall damage.
- 无跌落伤害。
- Unlimited carry weight.
- 无限负重。

## Requirements

- Fallout 4
- Fallout 4 Script Extender (F4SE)
- Address Library for F4SE Plugins
- Mod Configuration Menu (MCM)

GOE, Prisma UI Framework, LooksMenu, and DLC are not required.

不需要 GOE、Prisma UI Framework、LooksMenu 或任何 DLC。

## Scope

The effects are player-only, save-local, and controlled through MCM. No global GMST edits are used for the gameplay effects.

效果只作用于玩家，配置按存档保存，并通过 MCM 控制。玩法功能不使用全局 GMST 修改。
