# Aozora Light Gameplay Tweaks v1.1.0

A small player-only convenience mod for Fallout 4.
一款轻量、仅作用于玩家的 Fallout 4 便利调整 MOD。

Adds fast AP recovery outside combat and restores vanilla AP costs when combat begins.
新增非战斗状态 AP 快速回复，进入战斗后恢复原版 AP 消耗。

Adds water breathing, no fall damage, and unlimited carry weight through MCM-controlled player effects.
通过 MCM 控制玩家效果，提供水下呼吸、无跌落伤害和无限负重。

The plugin is ESL-flagged and does not require GOE, Prisma UI Framework, LooksMenu, or DLC.
插件已标记 ESL，不需要 GOE、Prisma UI Framework、LooksMenu 或任何 DLC。

Requires Fallout 4, F4SE, Address Library for F4SE Plugins, and MCM with matching versions.
需要 Fallout 4、F4SE、Address Library for F4SE Plugins 和版本匹配的 MCM。

This release is provided in separate Chinese and English packages for manual installation or distribution.
本版本提供中英文独立压缩包，可手动安装或发布。
